# Project Brief

## Project Name

Madhv Darji — 3D-Inspired Developer Portfolio

## Project Summary

Build a premium, interactive portfolio website for Madhv Darji using a creative 3D-inspired visual direction.

The website should combine:

* Large expressive typography
* Dark and light section contrast
* 3D-inspired imagery
* Smooth scroll animations
* Magnetic interactions
* Sticky project cards
* Strong project presentation
* Responsive frontend engineering

The experience should feel closer to a creative studio website than a traditional developer resume.

## Professional Positioning

Madhv Darji is a software developer with experience in React.js, JavaScript, full-stack development, SQL, and foundational machine learning.

The portfolio should communicate:

> A software developer who builds thoughtful, responsive, and impactful digital experiences.

The visual identity can be highly creative without falsely presenting Madhv as a professional 3D artist.

## Target Audience

* Recruiters
* Software-development hiring managers
* Internship and entry-level hiring teams
* Potential collaborators
* Developers and technical peers
* People evaluating frontend and full-stack projects

## Primary Goals

1. Make a strong first visual impression.
2. Present Madhv's projects in a memorable way.
3. Showcase frontend and full-stack capabilities.
4. Communicate technical depth without overwhelming visitors.
5. Make the website responsive and performant.
6. Provide clear contact and social links.
7. Create a portfolio that can evolve as Madhv gains more experience.

## Visual Direction

The design should be:

* Dark
* Premium
* Minimal but expressive
* Typography-led
* 3D-inspired
* Motion-rich but not distracting
* High contrast
* Responsive
* Modern
* Editorial / creative-studio inspired

Primary dark background:

`#0C0C0C`

The design should use large headings, rounded containers, carefully controlled spacing, and smooth transitions.

## Reference Direction

The supplied reference portfolio is used as visual inspiration for:

* Hero composition
* Typography scale
* 3D visual placement
* Scroll-based motion
* Marquee presentation
* About-section composition
* White services section
* Sticky project-card presentation

The portfolio must use Madhv's own identity, content, and project information.

## Content Source

Personal and professional information should come from the supplied resume.

Missing information such as:

* GitHub URL
* LinkedIn URL
* Final project URLs
* Hero photo
* Final project screenshots

will be added when provided.

## Initial Content Strategy

The website should showcase:

* Jeevan Deep Investment
* AI Resume Optimizer & Career Intelligence Platform
* SMS Spam Classifier
* CookVerse

The strongest projects should receive the most visual attention.

## Future Improvements

Possible future additions:

* Detailed project case-study pages
* Contact form
* More project screenshots
* Custom 3D hero visual
* Dark/light theme options
* Blog or writing section
* Downloadable resume
* Additional interaction polish

These are not part of the initial implementation unless explicitly requested.
